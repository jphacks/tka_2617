# Handoff: Pitari アプリシェル（案 3a ファッションEC風）

対象 Issue: https://github.com/jphacks/tka_2617/issues/12 「画面の骨組みを作る」

## Overview
Pitari は、服を撮影してクローゼットに保存し、体型を変えられる3Dアバターに着せるアプリ。
この資料は、3画面（`/` クローゼット・`/capture` 撮影・`/avatar` アバター）と、共通の下部ナビの見た目と動きを定める。
採用案は **3a（ファッションEC風）**：白基調、#222 の文字、控えめな角丸、写真が主役。

## About the Design Files
同梱の HTML は **デザインの参考資料**（見た目と挙動を示すプロトタイプ）で、本番コードではない。
`apps/web` の既存 Next.js（App Router）構成に、**Tailwind** で作り直すこと。
- `CLAUDE.md` と `apps/web/AGENTS.md` のルールを優先する
- import は `@/` を使う
- 新しい依存は追加しない（アイコンはインライン SVG で書く）
- 必要以上に共通化しない（共通化するのは下部ナビ程度）

## Fidelity
**High-fidelity。** 色・文字サイズ・余白・角丸は下記の値に合わせる。
ただし、プロトタイプにはスマホの枠（390×844、角丸44px）があるが、これは表示用なので実装しない。

## Issue #12 の範囲で実装するもの／しないもの
実装する：
- 3画面のタイトル・短い説明・空状態
- クローゼットから撮影画面へ進む「服を登録する」導線
- 撮影・アバターは「準備中」と分かる表示
- 共通の下部ナビ（選択状態付き）

実装しない（プロトタイプにはあるが、今回は入れない）：
- **「登録後の表示イメージ」のサンプルカード2枚とハート** → 架空の服を表示しないため
- **検索バーとカテゴリタブ** → データが無く絞り込む対象が無いので、今回は入れないことを推奨する（入れる場合は下の仕様のとおり、実際に状態が切り替わること）
- API・DB接続、カメラ撮影、3D表示、体型保存

## Layout（全画面共通）
- 背景 `#FFFFFF`、文字 `#222222`、フォント：Noto Sans JP（無ければ system-ui）
- コンテンツ列：スマホは全幅。PC では `max-w-[480px] mx-auto` で中央寄せし、左右に `#F5F5F5` の余白を見せる想定
- 下部ナビは `fixed bottom-0`。本文は `padding-bottom` をナビの高さ＋セーフエリア分取り、ナビで内容が隠れないようにする（例：`pb-[calc(56px+env(safe-area-inset-bottom))]`）
- 横はみ出し禁止（`overflow-x-hidden` は最後の手段。`min-w-0` と `minmax(0,1fr)` で解決する）

## 下部ナビ（共通・client component）
- `fixed inset-x-0 bottom-0`、背景 `#FFFFFF`、上線 1px `#EEEEEE`、padding `4px 8px calc(env(safe-area-inset-bottom) + 8px)`
- 3等分グリッド。各項目は `<Link>`、最小高さ 52px、縦並び gap 3px：アイコン 24px ＋ ラベル 10px
- 選択中：色 `#222222`、ラベル 700、アイコンの線 2.2px、`aria-current="page"`
- 未選択：色 `#999999`、ラベル 400、アイコンの線 1.6px
- 現在のパスは `usePathname()` で判定
- 項目：クローゼット `/`（ハンガー）・撮影 `/capture`（カメラ）・アバター `/avatar`（人型）

## Interactions & Behavior
- 画面切り替え時、本文を `opacity 0→1` で 250ms ease-out フェードイン（任意。`prefers-reduced-motion` では無効）
- フォーカス表示：`focus-visible:outline-2 outline-offset-2 outline-[#222222]`
- タップ領域は最小 44×44px

## State Management
- Issue #12 の範囲ではサーバーデータ無し。登録件数は常に 0 件として空状態を出す（ハードコードの架空データは置かない）
- 検索・カテゴリを入れる場合のみ：`query: string`、`category: string` を client state で持つ

## Design Tokens
- Colors：`#FFFFFF` 背景 / `#222222` 本文・主ボタン / `#666666` 説明文 / `#777777` 補助 / `#999999` 未選択・プレースホルダー / `#BBBBBB` 枠マーク / `#DDDDDD` 小ボタン / `#EEEEEE` 区切り線 / `#F5F5F5` 補助背景
- Radius：4px（ボタン・画像枠・タグ）、6px（検索バー）、9999px（円アイコン）
- Font sizes：10 / 11 / 12 / 13 / 14 / 15 / 16px
- Spacing：4 / 8 / 12 / 14 / 16 / 20 / 24 / 36 / 40px
- Shadow：使わない
