# 写真からの採寸

初期版はローカルCPUで推論する。クラウドGPUは契約しない。1枚に1着を平置きし、実物のA4用紙（21cm×29.7cm）を同じ平面に置く。表裏の写真を登録すると、PC内でテクスチャを生成する。

## 計算方法

番号はDeepFashion2のカテゴリ内で1始まり。測定用画像の座標で計算し、画像のpixelsPerCmでcmへ換算する。

| カテゴリ         | 項目            | 計算               |
| ---------------- | --------------- | ------------------ |
| short_sleeve_top | shoulderWidthCm | 距離(7,25)         |
| short_sleeve_top | sleeveLengthCm  | 距離(7,9)          |
| short_sleeve_top | bodyWidthCm     | 距離(12,20)        |
| short_sleeve_top | bodyLengthCm    | 距離(1,16)         |
| long_sleeve_top  | shoulderWidthCm | 距離(7,33)         |
| long_sleeve_top  | sleeveLengthCm  | 距離(7,11)         |
| long_sleeve_top  | bodyWidthCm     | 距離(16,24)        |
| long_sleeve_top  | bodyLengthCm    | 距離(1,20)         |
| trousers         | waistCm         | 距離(1,3)×2        |
| trousers         | hipCm           | 距離(4,14)×2       |
| trousers         | thighWidthCm    | 距離(9,14)         |
| trousers         | riseCm          | 距離(2,9)          |
| trousers         | inseamCm        | 距離(9,中点(7,11)) |
| trousers         | hemWidthCm      | 距離(11,12)        |

shirtはlong_sleeve_topと同じ点・計算を使う。DeepFashion2にシャツのカテゴリはなく、推論では長そでとして検出する。

股下は利用者指定の中点方式。一般的な片脚の縫い目に沿った股下と異なり、脚の開き方で変わる。ウエストとヒップは周囲長の近似値。その他は2倍しない。全項目がブランドの採寸方法と一致するわけではない。現在のバージョンは`df2-a4-flat-midpoint-v2`。v1から点番号の式は変えず、遠近補正を廃止した。

## 画像と点

アップロード前に向きを正して縦横比を保ち、長辺1600px以下のJPEGへ描き直してEXIFを除去する。以後、この画像を変形しない。A4四隅・服の範囲・ランドマークはすべてこの画像のピクセル座標。モデル内部の切り抜き・縮小座標もこの画像へ戻す。表示サイズの座標は保存しない。

A4の向かい合う辺の長さを平均し、大きい方を長辺、小さい方を短辺とする。`pixelsPerCm = (長辺px / 29.7 + 短辺px / 21) / 2`。平置き・真上撮影を前提に、四隅の凸性・画像内の位置・直角からのずれ・向かい合う辺の差・縦横の縮尺の差を検証する。大きく外れた場合は補正せず縮尺をnullにする。

A4を自動検出して測定し、結果上で四隅をドラッグ修正できる。用紙以外の長方形を拾う場合は手動修正する。検出は、まず3色とも明るい白い領域から、A4の縦横比で直角に近い四角形を探す。木の机のように紙と色が近い背景や、紙に物が触れている写真では輪郭線が途切れたりつながったりするため。白い画素の輪郭は紙の縁より半画素内側なので各辺を半画素外へ出し、しきい値ごとに見つけた同じ紙の四隅を平均する。白い四角形が無いときだけ、輪郭線の四角形から探す。点の確信度は可視性vと別で、HRNetのスコアを可視性へ変換しない。信頼できない点は未設定とし、必要な寸法を数値入力で補う。

利用者向け画面には服のランドマークの点・番号・編集操作を表示しない。内部の点を使い、肩幅・袖丈・身幅・着丈、またはウエスト・ヒップ・わたり幅・股上・股下・裾幅の区間を両端矢印と寸法名で示す。必要な点が不足する区間には矢印を表示しない。結果の初期表示は「寸法」で、A4・服の範囲の調整点はそれぞれのモードでのみ表示する。

「寸法を測定」でA4→服のカテゴリ・範囲→ランドマーク→背景切り抜きを実行する。進捗は各工程の開始位置と経過時間から求める目安を1%刻みで表示し、経過秒数も示す。次の工程へ進むまではその境界を超えず、100%は全処理が完了したときだけ表示する。残り時間や推論内部の実測割合ではない。A4の変更では縮尺・寸法・切り抜きを、服の範囲の変更ではランドマーク・寸法・切り抜きを更新する。寸法を直接入力した項目は点の修正で上書きしない。

切り抜きはOpenCVのGrabCutを使う。A4と範囲外を背景として指定し、服の最大連結領域を透過PNGとして保存する。ズボンはランドマークの14点で囲んだ輪郭の外も背景として教え、脚の間の床を除く（[ADR 0024](adr/0024-trousers-cutout-with-landmarks.md)）。服と背景が同系色の場合や薄い部分では失敗することがある。プレビューを確認し、範囲を直して再生成する。切り抜きはクローゼット表示用で、UVテクスチャではない。

登録時は画面で確定した寸法（手入力の修正値を含む）を服と一緒に保存する。クローゼットと撮影画面内の一覧は保存済みの寸法をcm付きで表示し、値のない項目は「未測定」とする。

## 検証

まず重みの取得、CPUでの推論、肩幅の計算を確認する。初回ロードと2回目以降の推論時間を分ける。実物のメジャーで同じ点を測り、cmの誤差・撮り直しのばらつき・手動補正率を記録する。ランダムな重みで得た結果を服の推論結果として扱わない。
