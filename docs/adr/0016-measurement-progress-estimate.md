# 採寸中は細かな進捗の目安と経過時間を表示する

日付：2026-10-13

## 背景

採寸の進捗が25%ごとにしか変わらず、推論に時間がかかると止まって見える。

## 決定

各工程の開始位置と経過時間から進捗の目安を計算し、1%刻みで表示する。「進み具合の目安」と明記し、経過秒数を添える。説明は「写真を確認しています」「サイズを測っています」などの短い言葉にする。

サーバーの応答を待つ間は、次の工程の境界を超えない。100%は、すべての処理が正常に終わったときだけ表示する。待ち時間が長くても、経過秒数と処理中の表示を続ける。失敗したら進捗を閉じ、既存のエラー表示に戻す。

## 理由

途中経過を返さない現在の推論APIを維持しながら、待っている間の状態を確認できる。目安であることを明記し、実測した処理割合や残り時間と混同させない。

## 代替案

推論内部の進捗を配信する方法は、API・BFF・推論サービスの通信方式の変更が必要になるため、今回は採らない。

## 影響

進捗表示用のタイマーは表示を閉じると解除する。測り直すときは、進捗と経過時間も最初から始める。登録済みの寸法は既存の保存処理を使い、クローゼットのカードにも表示する。DB・APIの形式は変更しない。
