# ローカルCPUによるDeepFashion2採寸

日付：2026-10-10

## 背景

TシャツとパンツをA4用紙と一緒に平置きで撮り、撮影後数秒で寸法を確かめたい。手元のPCはIntel Iris Xeと約16GBメモリで、NVIDIA GPUがあるかは確認できていない。

## 決定

Pythonの推論サービスをapps/inferenceに追加し、Honoから呼ぶ。DBとStorageはHonoだけが扱う。最初はCPUで学習済みHRNetを確かめる。重みをまだ置いていなくても、A4補正・手動採寸・登録は使えるようにする。推論できたようには見せない。自動検出には任意でGrounding DINOを使う。費用のかかるクラウドは契約しない。

## 理由

ひな形で分けた役割を保ち、重みの入手と速度の検証を、webの作業とは別に進められる。

## 代替案

GPUクラウドを使うかは、ローカルで実測してから決める。独自に学習するかは、既存モデルの精度を調べてから決める。テクスチャは3D担当の方針に合わせて後で追加する。

## 影響

Pythonの環境も起動する必要がある。採寸の定義は[measurement.md](../measurement.md)に固定する。股下はユーザー指定の両裾内側の中点を使い、一般的な股下との差を画面にも示す。重みと写真はgitへ含めない。
