# 0045 今日のコーデは、気温で袖を、季節と素材で服を絞り、合わせやすい色の組み合わせを日ごとに回して選ぶ

日付：2026-10-18

## 背景

今日の画面（[ADR 0041](0041-today-as-home.md)）で、クローゼットの服から上と下を1着ずつ提案し、アバターに着せて見せたい（#113）。毎朝Pitariを開く理由にするため。生成AI（LLM）は使わず、決まったルールで選ぶ。

使える情報は、朝・昼・夜の気温と季節（[ADR 0040](0040-today-weather-and-season.md)）、服の種類・季節・素材の混率（#109）・色の系統（[ADR 0044](0044-color-family-from-cutout.md)）。着た服の記録（#114）はまだ無い。

アバターに着せられるのは、登録した服のうち上と下の1着ずつ。シャツの下のTシャツ（#65）は見本の服で、クローゼットの服は重ねられない。

## 決定

- トップスとボトムスが1着ずつあれば提案する。靴の種類はまだ無く、アバターは見本の靴を履くので、靴は数えない。
- 寸法が足りずアバターに着せられない服は、提案に使わない。
- 袖：朝・昼・夜のうち、いちばん高い気温が25°C以上なら半袖（Tシャツ）、それより下なら長そでかシャツ。気温を読めなかったら、袖では絞らない。
- 季節：服に季節を付けていて、今日の季節が入っていなければ選ばない。季節を付けていない服は、いつでも選ぶ。
- 素材：いちばん割合の多い素材で見る。夏はウール・カシミヤ・アクリル、冬は麻の服を選ばない。
- 天気を読めず季節が分からないときは、季節と素材では絞らない。
- 色：どちらかが白・黒・グレー・紺・ベージュの組み合わせを先に選ぶ。ボトムスの青（ジーンズ）も、何とでも合わせやすい色に入れる。次は色が分からない服（null）を含む組み合わせ、最後はどちらも色みの強い組み合わせ。
- 同じ順位の組み合わせが複数あれば、下を同じにして上を替えていく順に並べ、日本の日付が変わるたびに次の組み合わせにする。同じ日は何度開いても同じ組み合わせ。
- 合う服が無いときは、足りない服を決まった文で出す（「長そでのトップスかシャツがあると、合わせやすいです」など）。
- 朝か夜が15°Cを下回るときは、「朝や夜は冷えるので、上着を足すと安心です」と添える。上着の種類はまだ無い。
- 選んだ理由（「25°Cまで上がるので、半袖にしました」など）を、組み合わせと一緒に出す。

## 理由

- 決まったルールなら、なぜその服になったかを画面で説明でき、テストで確かめられる。LLMを呼ぶと、apiの外へ服の情報を送ることになり、応答も毎回変わる。
- 25°Cは、気象庁が「夏日」とする最高気温の境目。日中に着ている時間が長いので、いちばん暖かい時刻で決め、朝晩の冷えは文で補う。
- 素材は混率の少ない分まで見ると、綿にウールが少し入っただけの服も夏に外れてしまう。
- 何とでも合う5色は、#112で色の系統を決めたときに見分けられるようにした色（ADR 0044）。ジーンズは、ADR 0044の分け方では濃ければ紺、明るければ青になる。濃いジーンズだけを合わせやすい色として扱わないよう、ボトムスの青も入れる。
- 下を同じにして上を替える順にしたのは、毎朝上の服が変わるほうが、違うコーデに見えるため。

## 代替案

- 生成AIに服の一覧を渡して選ばせる：理由を説明しにくく、テストもしにくい。#113で使わないと決めていた。
- 毎回ランダムに選ぶ：開くたびに変わり、朝に見た組み合わせが昼に変わってしまう。
- 気温を朝・昼・夜の平均で見る：朝晩の冷え込む日に、日中に暑い長そでを提案してしまう。
- 季節を付けていない服を選ばない：前からある服は季節が空なので、ほとんど提案できなくなる。

## 影響

- 着た服の記録（#114）ができたら、最近着た服を後回しにする。
- 体に対して小さすぎる服も提案に入る。アバターの画面と同じく「小さすぎて着られません」と出す。着られない服を外すには、提案の前にアバターの体で寸法を比べる必要がある。
- 色の組み合わせは系統だけで見るので、柄物も単色として扱う。
- 見直す条件：上着や靴の種類を足すとき、着た服の記録を足すとき、提案に意見が出たとき。
