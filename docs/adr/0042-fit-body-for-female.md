# 0042 女性の服は、胸の谷間と胸の下を埋めた「着せるための体」に着せ、身幅の判定に胸の一周も使う

日付：2026-10-18

## 背景

[ADR 0034](0034-male-avatar-first.md)のとおり男性のアバターで通しで動いたので、女性のアバターを足す。体はMPFBのマクロ`gender`だけを女性にし、体型4つ・身長キー2つは男性と同じ作り方にする。胸の大きさ（`cupsize`）は0.5で固定する。

男性と同じ服（`male_casualsuit06`など）をmhcloで女性の体に着せ直すと、服が体の形をそのままなぞる。

- 左右の胸の間（谷間）に布が入り込む
- 胸の下で、布が体に沿って内側へ戻る

本物の布は、胸の一番前の所に掛かって左右に渡り、胸から下へまっすぐ落ちる。突き抜け対策は「服を体の外へ押し出す」だけで、体は変形させない（[ADR 0007](0007-push-shirt-out-only.md)）ので、押し出しの相手を本物の体にすると、押し出した後も谷間と胸の下に沿ったままになる。

服が着られるかは身幅で決めている（体の身幅＝脇の下1cm下の胴の一周÷2）。女性は胸の一番高い所が脇の下より下にあるので、脇の下だけでは胸の大きさが入らない。

## 決定

- 体とは別に、見えない「着せるための体」を作る（`pitari_female.fit_coords`）。本物の体の胸の前だけを前へ出したもので、次の2つを体の形から計算する
  1. 谷間を埋める：高さごとに、胴の切り口の前側を、左右のふくらみの外側で結ぶ（切り口の前側の凸包。ブラや巻き尺と同じ形）
  2. 胸の下を落とす：乳首の高さから下は、縦の列ごとに、前面をウエスト（胴の一周が一番短い高さ）へまっすぐ下ろす（縦の列の前側の凸包。お腹が出ていればお腹を通る）
- 服の着せ直し（mhclo）・押し出し・検証は、本物の体ではなく着せるための体に対して行う。mhcloは体のhelper（`helper-tights`）を基準に服を置くので、肌とhelperの両方に同じ計算をする
- 着せるための体は、体と同じ頂点の並び・体型キー・身長キー・`thumb_in`・`_cover`を持たせ、`avatar_female.glb`に別のメッシュ`avatar_fit`として入れる。ブラウザは描かずに、押し出しの相手にだけ使う
- 女性の体の身幅は、脇の下1cm下の胴の一周÷2と、着せるための体で胸の一番高い所（乳首の高さ）の一周÷2の、大きい方にする。男性は今のまま
- 検証（`verify_sizes.py -- tshirt female`）は、男性と同じ寸法の基準に加えて、「谷間に服の頂点が入っていない」「胸の下に、埋めた深さの0.9倍以上の服と体の間の空間がある」を合否に入れる

## 理由

- 形を手で決めず体の形から計算するので、体型キー・身長キーの体にも同じ計算ができる。あとで骨格（ストレート・ウェーブ・ナチュラル）のキーを足しても、同じ計算を流し直せば作れる
- 本物の体は変形させないので、ADR 0007の「体は変えない」を守れる。服だけが着せるための体の外に出る
- 胸の一周は巻き尺と同じく谷間を渡って測るので、服を買うときのバストの測り方に近い

## 代替案

- 服の形だけを後から直す（谷間・胸の下に入った服の頂点を前へ出す）：ブラウザの押し出しが本物の体に対して行われるので、服を細くしたときに、また谷間に引き込まれる
- 女性用の服（`female_casualsuit01`など）を使う：服ごとに基準点・UV・寸法の測り方・サイズキーを作り直すことになり、男性とUVが変わるとテクスチャのテンプレートも分かれる
- 本物の体の胸を変形させる：ADR 0007に反する。体の見た目が変わる

## 影響

- `avatar_female.glb`は、着せるための体の分だけ大きい（男性2.6MBに対して4.8MB）
- ブラウザの押し出し（`push-out.ts`）は、着せるための体があればそれに対して押し出す。`verify_sizes.push_out_e`も同じ
- 着せるための体は乳首の頂点（`nippleTip`）と腰の関節（`joint-spine-3`）を目印にする。MPFBの頂点の並びが変わったら作り直す
- `cupsize`0.5では、胸の一周は脇の下の一周とほぼ同じで、身幅の判定はたいてい脇の下で決まる。胸を大きくしたときに効く
- 見直す条件：骨格のキーを足すとき（体型4つと組み合わせるか置き換えるか）、胸の大きさを選べるようにするとき
