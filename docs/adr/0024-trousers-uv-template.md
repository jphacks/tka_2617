# ズボンのテクスチャは、脚ごとのUVの島を前後に分けて表と裏の写真を貼る

日付：2026-10-17

## 背景

Tシャツと同じく、ズボンも表と裏の写真から服ごとのテクスチャを作りたい（[ADR 0015](0015-uv-template-for-photo-texture.md)、[ADR 0022](0022-garment-texture-on-pc.md)）。`pitari.blend`のズボン（`Human.male_casualsuit06.001`）には、MakeHuman由来の`UVMap`しかない。Tシャツのように専用に展開したUVはない。

## 決定

`UVMap`をそのまま使い、Tシャツと同じ形のテンプレート（`artifacts/uv/pitari/trousers/uv_template.json`）を`build_trousers_template.py`で作る。

- UVは左右の脚で1つずつの島で、前後中心の縫い目と股の縫い目で切り開かれている。各島を前半分と後ろ半分に分け、表の写真を前、裏の写真を後ろへ貼る。
- 前後の境目は、外側は平置きで折れる線（高さごとに切った断面で最も外に出ている点）、内側は股の縫い目とする。
- 写真側の固定点は、ウエストの両端（1・3番）と中心（2番）、股（9番）、裾の外側と内側（6・12番、7・11番）。腰・膝の点（4・5・8・10・13・14番）は位置の定義が曖昧なので、輪郭の割合で代わりに決める。
- 股は推論の9番ではなく、脚の間のすき間の一番上（服の輪郭）に合わせる。9番は前（後ろ）中心の縫い目の上に出やすいため。
- 内部の点は、三角形の辺に沿った平均値座標の重みで解く（`mean_value_embedding`）。Tシャツの方式（輪郭全体からの重み）では、股のように形が大きく変わる所で三角形が裏返った。
- 服の領域は、股の付近の細い割れ目や出っ張りをならすため、写真の長辺の1.5%で閉じてから開く。

## 理由

既存のUVを使えば、Blenderで展開し直さずに作れる。テンプレートの形をTシャツとそろえたので、変換の本体（`photo_to_texture.make_texture`）と推論サービスの処理は共通のまま、カテゴリでテンプレートを選ぶだけで済む。

## 代替案

- ズボンのUVを前後の島に展開し直す：Blenderでの手作業が必要で、アプリのGLBもまだない。
- 内側の境目も断面から求める：股の縫い目がやや前にあるため、前の部位が島の両端に分かれ、部位の多角形が作れない。
- Tシャツの内部点の方式を使う：股で三角形が裏返った。Tシャツは結果が変わらないよう、今の方式のままにした。

## 影響

股の縫い目を内側の折り目とみなす近似のため、脚の内側の細い帯には裏の写真が入る。股を下から見ると、写真の床や影の色が出ることがある。テクスチャは`pitari.blend`のズボンのUV用で、Tシャツと材質を共有しているため、使うときはズボン専用の材質が必要。アプリにはズボンの3Dモデル（体型・身長・寸法で変形するGLB）がまだない。作るには、Tシャツと同じBlender 4.2・MPFB2・MakeHumanの服の素材が要る。試したのは実写1組（Wikimedia Commonsのジーンズの写真）だけ。
