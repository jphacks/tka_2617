# 0003 スマホ向けのアプリはPWAで作る

日付：2026-10-10

## 背景

Pitariは、服をスマホで撮影して使うので、スマホのアプリとして使いたい。ただ、ハッカソンの期間は短く、チームの3人はNext.jsで画面を作り始めている。

## 決定

- 今のNext.js（`apps/web`）を、スマホ向けのPWAにする
- `apps/web/src/app/manifest.ts`でアプリの名前、アイコン、全画面の表示（`display: "standalone"`）を決める
- iPhoneはSafariの共有ボタンから「ホーム画面に追加」、AndroidはChromeの「アプリをインストール」で入れる
- iPhone向けの「ホーム画面に追加」の案内は、今は画面に出さない。デモではチームが自分で追加すれば足りるため

## 理由

- 1つのコードで、iPhone、Android、PCのどれにも入れられる
- App StoreやGoogle Playの審査と開発者登録が要らない。デプロイすれば、すぐ全員に反映される
- Pitariで要るもの（カメラ、写真の送信、three.jsの3D）は、どれもWebでできる
- 新しい依存を足さずに、Next.jsの機能（`manifest.ts`、`apple-icon.png`）だけで作れる

## 代替案

- Swift（iPhone）とKotlin（Android）でネイティブのアプリを作る：OSの機能をすべて使えるが、同じ画面を2回作ることになり、審査も要る
- 今の画面をCapacitorなどでネイティブのアプリに包む：ストアに出せるが、審査と開発者登録が要り、ビルドの手順も増える

## 影響

- ホーム画面に追加するにも、カメラを使うにも、HTTPSが要る。スマホで試すには、先にデプロイが要る（Macだけなら`next dev --experimental-https`で試せる）
- PWAはSafariやChromeのエンジンの上で動くので、LiDARやARKitなど、ネイティブのアプリだけが使える機能は使えない
- 今のアイコンは、ハンガーの線画で作った仮のもの。差し替えるときは`apps/web/src/app/icon.svg`、`apple-icon.png`（180px）、`apps/web/public/icons/`（192pxと512px）を置き換える
