# ローカルCPUによるDeepFashion2採寸

日付：2026-10-10

## 背景

TシャツとパンツをA4用紙と平置き撮影し、撮影後数秒で寸法を確認したい。手元はIntel Iris Xe、約16GBメモリで、NVIDIA GPUは確認されていない。

## 決定

Python推論サービスをapps/inferenceへ追加し、Honoから呼ぶ。DBとStorageはHonoだけが扱う。最初はCPUで学習済みHRNetを検証する。重み未配置でもA4補正・手動採寸・登録を使えるようにし、推論できたように見せない。自動検出には任意でGrounding DINOを使う。費用のかかるクラウドは契約しない。

## 理由

ひな形の境界を維持しつつ、重みの入手・速度検証とwebの作業を独立して進められる。

## 代替案

GPUクラウドはローカルの実測後に判断する。独自学習は既存モデルの精度を評価してから行う。テクスチャは3D担当の方針に合わせて後で追加する。

## 影響

Python環境の起動が必要。採寸の定義は[measurement.md](../measurement.md)に固定する。股下はユーザー指定の両裾内側の中点を使い、一般的な股下との差を画面にも示す。重みと写真はgitへ含めない。
