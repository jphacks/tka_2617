# 0039 アバターの服の寸法は、基準寸法の半分から2倍までをモデルへ渡し、確かめた範囲の外は案内だけ出す

日付：2026-10-17

## 背景

アバター画面の服の寸法は、空欄でなく数値なら、0や負数、1000000cmでもそのままサイズキーの計算へ渡っていた（#85）。入力の途中や打ち間違いで、服の形が裏返ったり、大きく伸びたりする。

APIは寸法を0より大きく1000cm以下に制限しているが、モデルがまともに変形できる範囲はもっと狭い。一方で、Blenderで形を確かめたのは基準寸法の近くだけで、オーバーサイズの服などは、その範囲を超えやすい。

## 決定

- 寸法は、その体型・身長の基準寸法（`fit.base`、`trouserFit.base`）と比べて確かめる（`apps/web/src/lib/size-check.ts`）
- 次の値はモデルへ渡さない。欄に直す内容を出し、直すまで最後の正常な形を保つ
  - 空欄、数値でない値、0以下
  - 基準寸法の半分より小さい値と、2倍より大きい値
- Blenderで形を確かめた範囲の外の値は、モデルへ渡すが、欄に「確かめた範囲の外なので、形がずれることがあります」と出す
  - 上の服（Tシャツ・長そで・シャツ）は、基準寸法からの差で、着丈−6〜+10cm、身幅−16〜+10cm、肩幅−4〜+5cm、袖丈−5〜+10cm（`verify_sizes.py`）
  - ズボンは、サイズキーの値で確かめた範囲（`verify_trousers.py`の`KEY_SETS`）を、キー1.0をおよそ1cmとしてcmの差に読み替える
- 手で入れた寸法も、APIから読んだ登録した服の寸法も、同じ確かめ方をする。登録した服の寸法も入力欄の値を通してモデルへ渡るため

## 理由

- 基準寸法との比で決めれば、体型や身長、服の種類が変わっても、同じ決まりで使える
- 半分と2倍は、人の服の寸法として明らかにおかしい値を止めるための線で、形が壊れる境目をBlenderで測ったものではない
- 確かめた範囲の外を止めると、オーバーサイズの服など、実際に登録した服を着せられなくなる。形が少しずれても、着た様子を見せるほうを選んだ

## 代替案

- 確かめた範囲の外は受け付けない：いちばん安全だが、登録した服でも着せられないことが増える
- 確かめた範囲の端に丸める：形は崩れないが、大きい服が実際より小さく見え、「着られるか」の判定もずれる
- 何もしない（今まで）：0や負数で形が壊れる

## 影響

- 半分と2倍の線で形が壊れないかは確かめていない。壊れる例が見つかったら、線を狭めるか、Blenderで確かめる範囲を広げる
- Blenderで確かめる範囲を変えたら、`size-check.ts`の`TOP_VERIFIED`と`TROUSER_VERIFIED`も合わせる
- 「着られるか」の判定（`fitStatus`）も、モデルへ渡した寸法（最後の正常な値）で出す
