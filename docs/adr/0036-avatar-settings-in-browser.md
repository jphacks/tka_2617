# 0036 アバターの設定は、ログインを入れるまでブラウザのlocalStorageに保存する

日付：2026-10-17

## 背景

アバターの身長や体型は画面の中にしか無く、再読み込みすると消えていた。初めて使う人が体の情報を入れる流れも無かった（#74）。[ADR 0009](0009-build-instead-of-weight.md)では、保存先を決めていなかった。

## 決定

- 設定の項目は次の7つ。名前、選べる値、初期値は`apps/web/src/lib/avatar-settings.ts`にまとめる

  | 項目   | 名前        | 値                                                                                                                               |
  | ------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
  | 性別   | `gender`    | `male`（男性）・`female`（女性）・`unspecified`（選ばない）                                                                      |
  | 身長   | `heightCm`  | 150〜195cm（[ADR 0008](0008-height-keys-and-tables.md)）                                                                         |
  | 体型   | `build`     | `slim`・`standard`・`broad`・`chubby`（ADR 0009）                                                                                |
  | 骨格   | `bodyFrame` | `straight`（ストレート）・`wave`（ウェーブ）・`natural`（ナチュラル）・`unknown`（わからない）。女性のときだけ持ち、ほかは`null` |
  | 肌の色 | `skinColor` | `presets.json`の`skinColors`                                                                                                     |
  | 髪型   | `hairId`    | `presets.json`の`hair`のID。髪なしは`null`                                                                                       |
  | 髪の色 | `hairColor` | `presets.json`の`hairColors`                                                                                                     |

- 初めてアバターの画面を開いたら、性別・身長・体型と、女性のときだけ骨格を聞く。肌の色と髪は初期値で始め、アバターの画面で変える
- 設定はブラウザのlocalStorage（`pitari.avatar`）に保存する。アバターの画面で変えるたびに保存し直す
- 今は、どの性別を選んでも男性のアバターを出す。女性を選んだときは、そのことを登録の画面に出す。骨格は3Dに使わず、女性のアバターを足したときに使う（[ADR 0034](0034-male-avatar-first.md)）

## 理由

- DBに保存すると、全員が同じデモユーザーなので設定を上書きし合う。さらに、身長や性別を、誰でも呼べる`/api/*`から返すことになる（[ADR 0002](0002-no-login-yet.md)の「個人を特定できる情報を返すAPIを足さない」）
- 初回に聞く項目を4つまでにすると、すぐにアバターの画面へ進める。肌の色と髪は、アバターを見ながら選ぶほうが選びやすい
- 骨格を今のうちに聞いておけば、女性のアバターを足したときに登録をやり直さずに済む

## 代替案

- `GET/PUT /v1/avatar`でDBの`avatars`に保存する（#10）：別の端末でも同じ設定を使えるが、上のとおり、ログインが無いうちは上書きと情報の漏れが起きる
- 7項目すべてを初回に聞く：最初から自分に近いアバターになるが、登録の画面が長くなる

## 影響

- 設定は端末とブラウザごとに分かれる。サイトのデータを消すと、登録からやり直しになる。localStorageを使えないブラウザでは、画面を開いている間だけ設定を使える
- 保存した値が壊れているか範囲の外なら、登録の画面に戻す
- ログインを入れたら、`/v1/avatar`とDBの`avatars`に移す。そのときは、localStorageの値を初回だけ送って移す
