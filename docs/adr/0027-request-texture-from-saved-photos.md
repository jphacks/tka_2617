# 保存済みの表裏写真からテクスチャを再生成できるようにする

日付：2026-10-17

## 背景

ズボンもTシャツと同じ操作で、アプリへの写真登録からPC内へのテクスチャ生成まで進めたい。カテゴリの切り替えと裏面保存時の自動生成依頼は実装済みだが、依頼の失敗はログにしか出ず、再生成には裏面の再登録が必要だった。

## 決定

Tシャツとズボンに共通で、服の詳細に「テクスチャを作る」を設ける。`POST /v1/garments/:id/texture`はプロフィールの所有確認後、保存済みのカテゴリ・measurement画像・back画像から推論サービスへ依頼し、受付成功時に202を返す。表裏の写真が不足していれば生成しない。

裏面保存時も生成依頼の受付結果を返し、画面に表示する。写真の保存と生成依頼の成功は区別する。依頼が失敗しても保存済み写真は残し、詳細のボタンから再試行できる。推論サービスへの受付待ちは15秒までとし、変換完了は待たない。

生成物は従来どおりPC内だけに保存する。画面は受付結果だけを表示し、完成画像・処理途中の写真・ローカルパスを返すAPIは追加しない。完了状態はPC内の`job.json`で確認する。

## 理由・代替案

裏面を撮り直す方式では、テンプレートの更新や推論サービスの復旧のたびに同じ写真を登録し直す必要がある。受付結果を待たずに成功表示する方式では、設定不備や待ちの満杯をユーザーが判断できない。

## 影響

新しい公開BFFも既存のapi認証とプロフィール確認を通す。写真・テクスチャの取得範囲は増やさず、既存の上限5件の推論キューを使う。DBとStorageの構造は変えない。受付後の変換失敗は画面には通知せず、PC内で確認する。
