# 0032 重ね着の「タイト」「小さすぎます」は、中の服1枚分の厚みを体の身幅に足して決める

日付：2026-10-17

## 背景

シャツの下にTシャツを着られるようにした（ADR 0019）。今の判定は、シャツもTシャツも、それぞれの身幅を体の身幅とだけ比べている（ADR 0007）。そのため、Tシャツを中に着ても、シャツの「タイト」「小さすぎます」は変わらない。また、伸び率の10%はTシャツ（ニット）に合わせた値で、ほとんど伸びない織物のシャツには大きすぎる。

## 決定

- 中のTシャツは、今のまま体の身幅と比べる。小さすぎるときは、Tシャツを着せない
- 中にTシャツを着たときは、外の服を「体の身幅＋Tシャツ1枚分」と比べる。1枚分は、押し出しで外の服を中の服から離す4mm（`push-out.ts`の`LAYER_OFFSET_M`）を厚みとみなした身幅の増え方で、π×0.4 ≈ 1.3cm（`LAYER_WIDTH_CM`）
- 中のTシャツが体より大きくても、余った分は足さない
- 外の服がTシャツの上からだと小さすぎ、体の上だけなら着られるときは、外の服だけを着せ、「Tシャツの上のシャツが小さすぎて着られません」と出す。タイトのときは「Tシャツの上のシャツがタイト」と出す
- シャツの伸び率を3%（`WOVEN_STRETCH_RATIO`）にする。重ね着をしないときも同じ値を使う。Tシャツと長袖は10%のまま

## 理由

- 見た目と判定を合わせられる。押し出しでは、外の服は中の服から4mm外に出るので、厚みとして足す量もこれに合わせた
- 余りを足さないのは、外の服に押されると、中の服の余りはしわになって寄るため。足す割合を決める根拠も無いので、説明しやすい方を選んだ
- 外の服を何も着せないより、外の服だけを着せた方が、どこが小さいのかが分かる
- 織物のシャツはほとんど伸びないので、ニットより小さくした。3%は仮の値で、実物で確かめていない

## 代替案

- 中の服の余りの一部（例えば3割）も足す：厚手の服の重ね着には近いが、割合の根拠が無い
- 押し出しの量（`onPushStats`）が大きいときにタイトと出す：見た目とは合うが、寸法での判定と食い違うことがある
- 伸び率を服ごとに登録する：素材に合わせられるが、今は撮影から素材が分からない

## 影響

- 重ね着をしないときも、シャツは前より「小さすぎます」が出やすくなる
- 判定は今も身幅だけで決める。肩幅・袖丈で着られない服は分からない
- 中の服を登録した服から選べるようになったら、`LAYER_WIDTH_CM`を服の厚みで変えるかを見直す
