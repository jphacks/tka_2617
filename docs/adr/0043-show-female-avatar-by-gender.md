# 0043 設定の性別が女性なら女性のアバターを出し、男性と「選ばない」は男性のアバターを出す

日付：2026-10-18

## 背景

[ADR 0034](0034-male-avatar-first.md)で、デモまではどの性別を選んでも男性のアバターを出すことにした。女性のアバター（体・Tシャツ・長袖・シャツ・ズボン・髪・靴・顔のパーツ）を作り（[ADR 0042](0042-fit-body-for-female.md)）、確認ページ（`/dev/tryon`）で女性に切り替えて、ブラウザで問題ないことを確かめた。

女性の3Dモデルは標準の身長が159.12cm（男性172.91cm）なので、Blenderで基準寸法とキーの効き方を測る身長を140〜185cm（男性150〜195cm）にしてある。

## 決定

- 設定の性別が女性なら、女性のアバター・服・髪・靴・顔のパーツを出す。男性と「選ばない」は、男性のものを出す（`modelGenderOf`）
- 入力できる身長は、3Dモデルの性別ごとにする（女性140〜185cm、男性150〜195cm、`heightRangeOf`）。性別を変えたら、保存している身長をその範囲に収める
- アバターの画面で性別を変えたら、その性別の3Dモデル・身長の表・見本の服で試着の状態を作り直す
- 骨格は、今は3Dに反映しない（骨格のキーは候補要件）

## 理由

- 性別と身長はもう登録で聞いて保存しているので、登録をやり直さずに女性のアバターに切り替えられる
- 身長の範囲は、Blenderで測った範囲の外だと服の寸法がずれるので、3Dモデルに合わせる
- 「選ばない」を選んだ人には、今の男性のアバターをそのまま出す。どちらかを選ぶ画面を足すより、変わることが少ない

## 代替案

- 「選ばない」は女性と男性の中間の体にする：MPFBのマクロ`gender`を0.5にした体と、服・髪・靴をもう1組作ることになる
- 性別と別に、アバターの体（男性・女性）を選ぶ項目を足す：登録の項目が増える。性別と食い違う組み合わせを選べる理由も今は無い

## 影響

- 女性で150cm未満、または男性で185cmより高い身長を保存していた人が性別を変えると、身長が範囲の端に変わる
- 女性の髪型の一覧の画像は、男性の体で描いたもののまま
- 見直す条件：骨格のキーを足すとき、「選ばない」の人から男性のアバターについて意見が出たとき
