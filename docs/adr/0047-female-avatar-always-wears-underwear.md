# 0047 女性のアバターはいつも下着を着け、上の服は下着の外へ押し出す

日付：2026-10-18

## 背景

女性のアバター（[ADR 0042](0042-fit-body-for-female.md)、[ADR 0043](0043-show-female-avatar-by-gender.md)）では、着せるための体が乳首の形を残しているので、服を押し出すと乳首の所で服が少し尖る。服が小さすぎて体だけを出すときや、髪型のサムネイル（長い髪は腰まで写る）では、胸がそのまま見える。

## 決定

- 女性のアバターは、いつも下着を着ける。MakeHumanの`female_sportsuit01`の上（胸を覆う丈の短いトップス、CC0）を本物の体にmhcloで着せ、体と同じ体型キー・身長キーを持たせて、`avatar_female.glb`に`underwear`として入れる
- ブラウザは下着をいつも描き、上の服（とシャツの中のTシャツ）は、シャツの中のTシャツと同じ重ね着の仕組み（`wraps`）で下着の外へ押し出す
- 髪型のサムネイルは、下着を着けた女性の体で描く（`presets/female/thumbs/`）

## 理由

- 下着の面は乳首の上をなめらかに覆う（乳首は下着の0.24〜0.6cm内側）。上の服を下着の外へ押し出せば、乳首の所で尖らない
- 体は変形させない（[ADR 0007](0007-push-shirt-out-only.md)）ままにできる。重ね着の押し出しはもうある

## 代替案

- 体の胸を下着の形にして色を付ける：描くのは体だけで軽いが、体を変形させることになる
- 着せるための体だけ乳首をならす：服は尖らなくなるが、服を着ていないときに胸が見える

## 影響

- 女性のときは、上の服の押し出しで下着の衝突判定が1つ増える（下着は911頂点）
- `avatar_female.glb`は下着の分だけ大きい（5.1MB）
- 下着の色は無地の明るい灰色。色を選べるようにするかは、要望が出たら考える
- `verify_sizes.py`は、今までどおり着せるための体に対してだけ押し出して確かめる（下着の重ね着はブラウザだけ）
