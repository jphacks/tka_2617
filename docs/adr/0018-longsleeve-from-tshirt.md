# 0018 長袖は、Tシャツの袖を手首まで伸ばして作る

日付：2026-10-15

## 背景

一般的な長袖（丸首のロンT）を試着できるようにしたい。素材は「CC0のみ」にしている。MakeHumanのsystem assets（CC0）にある長袖は、襟付きのボタンシャツ（`male_casualsuit01`、`male_casualsuit03`）だけだった。別に用意したコミュニティの素材集（`shirts02_ccby`）には丸首のニットなどがあるが、13着すべてCC-BYだった。

## 決定

- 長袖は、今のTシャツ（`male_casualsuit06`の上半分、CC0）の袖口から手首まで、腕に沿って輪を足して作る（`assets/blender/pitari_longsleeve.py`）
- 寸法の4項目（着丈・身幅・肩幅・袖丈）とキー名はTシャツと同じ。袖丈は肩先から手首の袖口まで
- 服データのカテゴリは`long_sleeve_top`（`docs/er.md`にあるもの）を使う
- CC-BYの素材は使わない

## 理由

- Tシャツの頂点を変えずに後ろへ足すので、基準点・寸法の測り方・サイズキーの作り方・検証をそのまま使える。検証は体型4種×身長9点で合格した（最大誤差0.60cm）
- ライセンスがCC0のままで済む
- 丸首のロンTの形そのものになる

## 代替案

- CC-BYの丸首のニット（`mindfront_knitted_sweater_02`）：形は自然だが、作者の表示が要り、ルールを変える必要がある。基準点を自動で求める処理がTシャツのUVの形に頼っているので、作り直しになる
- CC0の襟付きシャツ（`male_casualsuit03`）：ロンTではなく、基準点の求め方も作り直しになる

## 影響

- 足した部分は腕に沿わせて作った形なので、元からある布の形ほど自然ではない。ぽっちゃりでは、元の袖口の高さにうっすら線が見える
- UVは、Tシャツの部分にテクスチャ担当のTシャツのUV（`pitari`）を写し、足した前腕は袖の島を延ばして仮に作った。左右の島の袖がぶつかるので、前身頃と後身頃を上下に並べ直した。前腕のUVは、テクスチャ担当に確かめてもらう
- ブラウザの体の`_cover`はTシャツのもので前腕を含まないので、長袖では袖の中の腕・手を別に選んで、押し出しで確かめる
- 袖丈が腕より長いと、余った袖が手に垂れる（萌え袖）。垂れ方は標準体型で布のシミュレーションをして3つのキーにした。ほかの体型・身長でも同じ差を足すだけなので、手の大きさの違いは押し出しで合わせる
  - 先に、余った分を手首にためる方法と、袖口を広げて垂らす計算を試したが、親指やひじが袖から出て不自然だった
  - 親指は、袖が手にかぶさるときだけ体のキーで内側に曲げて袖の中に収める。袖の中に隠れる腕は描かない（輪の間からひじが出るため）
- 袖を伸ばす処理の中身（輪の数、ゆとり、手首の決め方）は`assets/blender/AGENTS.md`に書いた
