# 0009 アバターの体は、体重ではなく4つの体型から選ぶ

日付：2026-10-12

## 背景

最初の設計（`docs/api.md`、`docs/er.md`）では、アバターは身長（`height_cm`）と体重（`weight_kg`）を持つことにしていた。一方、男性アバターは、MPFBのマクロ`weight`（体重）と`muscle`（筋肉）を組み合わせた4つの体型を、Blenderでキーにして作ってある。

## 決定

- 体重は入力しない。体型を細身（`slim`）／標準（`standard`）／がっしり（`broad`）／ぽっちゃり（`chubby`）の4つから選ぶ
- APIは`{ heightCm, build }`、DBの`avatars`は`height_cm`と`build`を持つ

## 理由

- 同じ体重でも、筋肉で肩や胸が厚い体と、お腹や腰回りが出る体では、服の見え方が違う。体重の数字だけではこの違いを表せない
- 体型ごとに、体の形とmhcloで着せ直したTシャツの形をBlenderで作り、寸法の誤差も体型ごとに検証している。体重を連続した数値にすると、体重と身長の組み合わせごとに形を作る必要がある。そのすべてを検証することになる
- 最初に入力してもらう項目が、身長と選択肢1つで済む

## 代替案

- 体重（kg）を入力して、マクロ`weight`に変換する：数値で入れられるが、筋肉か脂肪かを表せず、変換の式も決める必要がある
- 体重と筋肉の量をスライダーで入れる：細かく表せるが、ユーザーには何を入れればよいかわかりにくい

## 影響

- 体型の中間（標準とぽっちゃりの間など）は表せない。細かい調整は候補要件に置いた
- 身長と体型は、ログインを入れるまでブラウザに保存し、初めてアバターの画面を開いたときに入力してもらう（[ADR 0036](0036-avatar-settings-in-browser.md)）。DBに保存するときは、`avatars`のmigrationで`build`を作る
- 体型を増やすときは、Blenderで体型キーを足し、検証スクリプトに体型を足す
