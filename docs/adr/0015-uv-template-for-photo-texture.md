# 服の写真をモデル固定のUVテンプレートで貼る

日付：2026-10-12

## 背景

平置きで撮った服の前面・背面の写真を、`pitari.blend`の半袖トップスのUVテクスチャへ変換したい。写真ごとにUV側の対応を作ると、写真側とUV側で三角形分割がずれ、首の穴や服の外をまたぐ三角形もできる。

## 決定

モデルごとに固定のUVテンプレート（ローカルで生成する`artifacts/uv/pitari/uv_template.json`）を作る。部位・マスク・固定点はBlenderの面と面コーナーのUVから作り、UV展開図の画像はなぞらない。DeepFashion2の番号は前面と背面で別の表にし、背面は未検証と明記する。写真側とUV側は、輪郭の区間・割合の点・平均値座標の内部点・三角形の3つ組を共通で使う。塗り残しは色ではなく、写真から取れた・推定で補った・未カバーの3つのマスクで管理する。

## 理由

点の名前と三角形をテンプレートに固定すれば、写真ごとに分割をやり直さず、対応がずれない。縫い目では同じ頂点が島ごとに別のUVを持つため、面と面コーナーまで保存する。DeepFashion2の点は輪郭の一部しか表さないため、輪郭の長さの割合と内部点で補う。

## 代替案

写真とUVを別々にDelaunay分割する案は、三角形の対応が崩れるため採らない。点の少ない三角形分割は胸を横切る細長い三角形になり、柄が折れて見えるため内部点を足した。UVの再展開は今回行わず、必要な変更として記録した。

## 影響

`pitari.blend`のUVやメッシュを変えたらテンプレートを作り直し、版を上げる。トップスとパンツが材質を共有しているため、写真のテクスチャを使う前にトップス専用の材質が必要。前後の切れ目が階段状で、袖に伸びがある。写真からの生成は試行用のスクリプトだけで、合成写真と実写1組で確認した。いろいろな服や撮り方での精度は未検証。元モデル・生成JSON・検証画像はGitに含めず、別途用意したモデルから再生成する。詳細は[テンプレートのREADME](../../artifacts/uv/pitari/README.md)。
