# 採寸を共通の撮影画面へ統合する

日付：2026-10-10

## 背景

GitHubのmainにクローゼット・撮影・アバターと下部ナビが追加された。一方、ローカルの採寸・登録機能は別の`/measure`に実装していた。

## 決定

共通レイアウト・下部ナビ・日本語フォントを維持し、`/capture`に採寸機能を組み込む。`/measure`は`/capture`へ転送する。クローゼットは実際の保存済みデータを取得し、空状態の見た目には既存のデザインを使う。取得失敗は空状態と区別する。

## 理由

画面担当が作った3画面の構成と、採寸担当の機能を同じ導線から利用できる。PCでも共通の480px幅に収まるよう、採寸欄は1列にする。

## 代替案

採寸画面へのリンクだけ追加する案では、撮影画面の準備中表示と実際の機能が食い違い、保存後もクローゼットが0件と表示されるため採用しない。

## 影響

API・DB・モデル・環境変数は従来の採寸機能を引き継ぐ。依存は追加しない。アバターは元の準備中表示を維持する。保存済み寸法の編集は撮影画面下部の一覧から行う。
