# 0041 最初の画面を今日のコーデにし、クローゼットを`/closet`へ移す

日付：2026-10-18

## 背景

下のメニューを「今日・クローゼット・＋・記録・マイ」の5つにする（#108）。毎朝開いて「今日なにを着るか」を見るアプリにするので、開いてすぐ今日の画面を出したい。今までは`/`がクローゼットだった。

## 決定

- `/`を今日のコーデの画面にし、クローゼットを`/closet`へ移す。服の詳細（`/garments/{id}`）は今までどおりで、戻り先と、メニューで「クローゼットの中」として扱う判定を`/closet`に直す。
- 記録は`/log`に置く。#114で作るまでは「準備中」と出す。
- マイは今の`/avatar`のまま、メニューと見出しの名前だけを変える。
- 撮影（`/capture`）はメニューの項目から外し、真ん中の＋から選ぶ。ZOZOから追加（#111）も＋に並べ、作るまでは押せない「準備中」にする。

## 理由

- PWAの`start_url`は`/`なので、`/`を今日にすれば、ホーム画面から開いたときに今日の画面が出る。
- マイの中身はアバターの画面そのもので、URLを変えると、着せる服を入れたリンク（`avatarUrl`）も直す必要がある。名前だけ変えれば済む。
- 服を足す入口を＋1か所にまとめ、撮影とZOZOのどちらで足すかを、そこで選んでもらう。

## 代替案

- `/`をクローゼットのまま、今日を`/today`に置く：ホーム画面から開いたときに今日が出ない。`start_url`を変えると、ホーム画面に追加し直すまで反映されない端末がある。
- `/avatar`を`/me`へ移す：上の理由で、変える箇所が増えるわりに得るものが無い。
