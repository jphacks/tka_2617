# シャツのテクスチャは、前後から投影したUVの外周を写真の輪郭に合わせて作る

日付：2026-10-17

## 背景

[ADR 0035](0035-choose-garment-type-first.md)でシャツを服の種類に足したが、UVテンプレートがないため、テクスチャは作らないことにしていた。シャツの受領素材（`pitari_shirt.blend`・`shirt_male.glb`・UV展開図・ランドマーク）がそろったので、ほかの種類と同じく、表と裏の写真からテクスチャを作りたい。

シャツのpitari UVは、長そでのような展開図ではない。面の向きで前と後ろに分け、前は正面から、後ろは背面からまっすぐ投影している（[ADR 0019](0019-shirt-from-casualsuit03.md)）。シャツは前が開き、襟があり、袖口が内側に折り返されているので、長そでのテンプレートの作り方（穴が4つ、前後の切れ目と袖付けの交点）は当てはまらない。

## 決定

シャツ専用の`build_shirt_template.py`で、ほかの種類と同じ形の`artifacts/uv/pitari/shirt/uv_template.json`を作る。

- 平置きの写真は真上から見た形なので、UVの前後の島の外周を、写真の服の輪郭に対応させる。輪郭のたどり方は、写真側と同じ関数（`photo_to_texture.py`）を使う
- 固定点は、3D用のランドマーク（肩先・脇・袖口の上下・裾の端・襟の付け根）を投影の式でUVへ写し、いちばん近い輪郭上の点にする。裾と後ろ襟の中心は、写真側と同じく両端の間の輪郭の中点にする
- 部位は前後それぞれ、身頃と左右の袖に分ける。袖付けは3Dの袖と身頃の境目の曲線を使い、写真では肩先と脇の間にその形を当てはめる
- 前の襟元は、写真では襟の内側が見えて輪郭に出ない。襟の付け根（2・6番）から襟元のV字の一番下（4番）までを直線で結び、それより上の襟の先は近くの色で補う
- 写真の検出・点・切り抜きは長そでとして行い、テンプレートだけをシャツ用にする（`photo_to_texture.MODEL_CATEGORIES`）。DeepFashion2の番号の対応も長そでと同じにする
- 受領したメッシュの面とUVのSHA-256をスクリプトに持ち、違う書き出しからは作らない（ズボンと同じ）
- アプリの`shirt_male.glb`のUVを正とし（[ADR 0037](0037-app-glb-uv-is-source.md)）、そのUVのSHA-256を型紙に記録する。照合のスクリプト（`verify_shirt_assets.py`）で、アプリのglbの頂点とUVがBlenderのBasisと一致するかを確かめる。ハッシュが変わっていないことも確かめる

## 理由

投影したUVは、平置きの写真とほぼ同じ見た目になる。外周どうしを合わせれば、長そでのように切れ目を3Dでたどらなくても、点の対応が素直に決まる。UV側と写真側で同じ輪郭の関数を使うと、合成写真の自己テストで仕組みの誤りを見つけやすい。

## 代替案

- 長そでの`build_template.py`を広げる：穴・切れ目・袖付けの前提がシャツと違い、前の開きや襟の分岐が増える
- シャツのUVを長そでと同じ展開図に作り直す：アプリのGLBのUVが変わり、3D側の作業が要る

## 影響

- シャツのテクスチャを依頼できるようになった。apiの400と、画面の「シャツはまだ作れない」の案内を外した
- テンプレートは受領素材から作り直す生成物で、Gitには含めない（`artifacts/uv/pitari/shirt/`）。ないPCでは、ほかの種類と同じく503になる
- 前の襟の先（UVの約0.9%）は写真の色ではなく近くの色になる。実写の点の位置（特に襟元の2・4・6番）は、まだ確かめていない
- シャツのメッシュやUVを作り直したら、テンプレートとSHA-256を作り直す
