# 0034 デモまではアバターを男性だけで作り、女性は時間があれば足す

日付：2026-10-17

## 背景

アバターの設定（性別、身長、体格、女性のときだけ骨格、肌の色、髪型、髪の色）を登録して保存し（#74）、3Dに反映する（#75）。今ある3Dモデルは男性だけで、体（`avatar_male.glb`）も服（`tshirt_male.glb`、`longsleeve_male.glb`、`shirt_male.glb`、`trousers_male.glb`）も男性の体に合わせて作っている。

女性のアバターを足すには、体と服のglbを作り直すだけでなく、身長の表、体型のキー、服の押し出しの確認（体型4種×身長9点）を、服ごとにすべてやり直すことになる。一方で、デモの見せ場である「撮った服をアバターに着せる」（#70）と「写真の柄を貼る」（#73）は、まだつながっていない。

## 決定

- デモまでは、アバターを男性だけで作る。男性のアバターで、登録した服を着せて写真の柄を貼るところまで、通しで動くようにする
- 性別は、#74の登録で聞いて保存する。どれを選んでも、今は男性のアバターを出す
- 骨格は、女性のときだけ聞いて保存する。今は3Dに反映しない
- 身長、体格、肌の色、髪型、髪の色は、男性のアバターに反映する
- 通しで動いてから時間があれば、女性のアバターを足す

## 理由

- 女性を足すと、Blenderの作業が体と服の4種類ぶん、まるごと増える。デモまでの時間では、見せ場のほうを先に仕上げたい
- 性別と骨格を今から保存しておけば、女性を足したときに、登録をやり直さずに切り替えられる

## 代替案

- 女性のアバターを先に作る：上のとおり作業が倍になり、服を着せる流れが間に合わなくなるおそれがある
- 性別を聞かない：女性を足したときに登録の項目を増やし、全員に聞き直すことになる。項目は話し合いで決めたものなので、聞くことは変えない

## 影響

- 女性を選んだ人にも、男性のアバターが出る。登録の画面で「今は男性のアバターで表示する」と伝えるかは、#74と合わせる
- 3Dのファイル名の`_male`は、女性を足すときのためにそのまま残す
- 見直す条件：#70と#73が男性のアバターで動いたとき。そこで女性のアバターに取りかかるかを決める
- 女性のアバターを足し、女性を選んだ人には女性のアバターを出すようにした（[ADR 0043](0043-show-female-avatar-by-gender.md)）
