# 採寸を共通の撮影画面へ統合する

日付：2026-10-10

## 背景

GitHubのmainにクローゼット・撮影・アバターと下部ナビが追加された。一方、ローカルの採寸・登録機能は別の`/measure`に実装していた。

## 決定

共通のレイアウト・下部ナビ・日本語フォントはそのまま使い、`/capture`に採寸機能を組み込む。`/measure`は`/capture`へ転送する。クローゼットは保存済みのデータを取得する。服が無いときの見た目には、既存のデザインを使う。取得に失敗したときは、服が無い状態と区別する。

## 理由

画面担当が作った3画面の構成と、採寸担当の機能を、同じ流れで使える。PCでも共通の480px幅に収まるよう、採寸欄は1列にする。

## 代替案

採寸画面へのリンクだけを追加する案は採らない。撮影画面の「準備中」と実際の機能が食い違い、保存後もクローゼットが0件のままになるため。

## 影響

API・DB・モデル・環境変数は従来の採寸機能を引き継ぐ。依存は追加しない。アバターは元の準備中表示を維持する。保存済みの寸法は、撮影画面の下部にある一覧から編集する。
