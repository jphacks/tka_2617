# 0019 長袖のシャツは、male_casualsuit03 のシャツを使い、前の開け閉めはキーで作る

日付：2026-10-17

## 背景

襟付きの長袖のシャツを試着できるようにしたい。1つのモデルで、前を閉める・少し開ける・開けるの3つを選べるとよい。素材は「CC0のみ」にしている。MakeHumanのsystem assets（CC0）の長袖のシャツは、`male_casualsuit01`（デニムのシャツ）と`male_casualsuit03`（ストライプのシャツ）だった。

## 決定

- `male_casualsuit03`のシャツの部分を使う。色は無地にする（元のストライプのテクスチャは使わない）
- 寸法の4項目・キー名・測り方はTシャツと同じ。基準点の見つけ方だけ、このシャツの形（UVの島9つ、前が左右に分かれた縁の輪）に合わせる（`assets/blender/pitari_shirt.py`）
- 袖丈キー・袖の垂れ方のキー・`_sleeve`は長袖（ADR 0018）と同じものを使う
- 前の開け閉めは、キー`shirt_close`（閉める）と`shirt_open`（開ける）で作る。両方0の元の形（襟元のV字）を「少し開ける」にする
- 確認画面の「上の服」にシャツを足し、シャツのときだけ前の開け方を選べるようにする

## 理由

- `male_casualsuit01`はシャツがズボンの中に入っていて、シャツとズボンが1つにつながった布だった。`male_casualsuit03`はシャツとズボンが別の部品で、裾を出して着る形だった
- `male_casualsuit03`の前は元から左右に分かれていて、前の縁を動かすだけで開け閉めを作れた
- 開け閉めをキーにすれば、ブラウザでは値を入れるだけで、スマホでの計算は増えない。体に入る部分は、今の押し出しで外へ出す
- 検証は体型4種×身長9点で合格した（最大誤差0.25cm）

## 代替案

- 布の物理演算で開けた形を作る：自然になりそうだが、Aポーズでは前身頃が重さで横へ開かないので、開いた形を作るには力を加える工夫が要る。まずはキーの形で足りるかを見る
- 前立てと襟がしっかりしたシャツの素材を探す：見た目はよくなるが、CC0で裾を出す形のものは見つかっていない

## 影響

- ボタンは元のテクスチャに描かれていたので、無地にすると見えない
- 閉めると、前は襟元まで閉じ、襟の先は前の中心で合う（襟の前側を首の軸の周りに回す）
- 開けると中の体が見える。シャツの下にはTシャツを着られる（2026-10-17に追加）
  - Tシャツを体とズボンの外へ押し出してから、シャツをTシャツの外へ押し出す（`push-out.ts`の`wraps`）
  - ズボンの上端と違い、Tシャツは肩や胸の上にも重なるので、水平ではなくTシャツの面の法線に沿って押す。襟ぐり・袖口・裾の縁の外にある頂点は比べない（前の開きからのぞくTシャツを、前の縁で覆おうとしないため）
  - 中のTシャツの実寸は、今はサンプルのTシャツで固定
- シャツの写真用のUV（`pitari`）は、前と後ろからまっすぐ投影して仮に作った（その後に追加）。テクスチャ担当に確かめてもらう
