# 長そでの登録と受領UVを使ったテクスチャ生成

日付：2026-10-17

## 背景

Tシャツ・ズボンに加え、受け取った長そでのモデルにも撮った写真を貼りたい。サイズ項目はTシャツと同じだが、DeepFashion2の長そでは33点あり、半袖の25点とは番号が違う。

## 決定

`long_sleeve_top`を画面・API・DB制約・推論に追加する。着丈・身幅・肩幅・袖丈の共通項目を使い、採寸点は長そでの定義へ切り替える。既存のHRNetの長そで用チャンネルを使う。表裏の写真登録・再生成・PC内への保存は既存フローに合わせる。

素材は`artifacts/uv/pitari/inputs/`以下へカテゴリごとに分け、元モデル・写真・バックアップを保持する。長そでのテンプレートは受領BlenderのBasisとpitari UVから生成し、受領GLBと照合する。半袖用のテンプレート生成処理を共用し、袖の判定とDeepFashion2の対応表を長そで用に切り替える。

## 影響

既存のDBでは、カテゴリの制約を広げるmigrationが要る。写真とテクスチャの公開範囲は変えない。長そでUVは前後の主要領域に加えて背面袖に小島を持つため、元のUVを保ったまま写真の前後に分類する。受領UVの小さな重なりは元モデルの制約として検証結果に残す。合成画像では変換を確認した。実写の分類と採寸の精度は、別に確かめる必要がある。
