# 0007 服が体に突き抜けるのは、服を体の外へ押し出して防ぐ

日付：2026-10-12

## 背景

体型・身長と服の実寸に合わせてTシャツをシェイプキーで変形させると、体が服を突き抜けて見える。体より小さい服や、体に近い脇・襟で起きやすい。作業フォルダでは、次の2つの対策を試作していた。

- A：服の下の体を、シェーダーで法線の内側へ一律2.5cm縮める
- E：体から近すぎる服の頂点を、体の外へ押し出す（three-mesh-bvhで体の最寄りの面を探す）

Aは、服の縁でぷつっと切らないよう、袖口や裾の外側3cmまで縮める量をなだらかに減らしていた。そのため、服から出ている二の腕や腰がくびれて見えた。

## 決定

- 突き抜け対策はEだけにする。体は変形させない
- Eは、押し出したあと、服で完全に覆われる体（avatarの頂点属性`_cover`が0.99以上）が服の外へ出ていれば、その面の頂点をさらに外へ足す。服の頂点の間隔が広い所で、面が体の盛り上がりの内側を通って体が出るのを防ぐため
  - 一番近い服の点より下にある体は比べない。`_cover`は基準の着丈で決めてあるので、着丈を短くすると裾より下に出た体も「覆われる所」のままになり、裾が下へ引っ張られてギザギザになるため（着丈−6cmで、着丈のずれが+2.3cmから−0.5cmになった）
  - 最後に、服の縁（裾・袖口・襟）の押し出し量を、縁に沿った両隣とならす
- 押し出しは、入力が止まってから0.3秒後に計算する
- 服の身幅が体の身幅（服の身幅と同じ高さで体を切った胴の一周÷2）の90%未満なら、「小さすぎます」と出して服を表示しない。体の身幅より小さく90%以上なら「タイト」と出す
- Aの処理（`cover-shrink.ts`、`_below_hem`属性、`COVER_SHRINK`）は消す。`_cover`はEで使うので残す

## 理由

- 体が常に自然な形のままになる。Aのくびれのような、服の外の崩れが出ない
- 普通の大きさの服なら、押し出した後の寸法は入力からほぼずれない。Blenderの検証スクリプトで、着丈−0.8〜−0.1cm、身幅−0.5〜+0.24cm、肩幅+0.14〜+0.51cm、袖丈±0.1cm以内だった（体より小さい服を除く。2026-10-13、押し出しを入れないサイズキーで測り直した）
- スマホ（中央値）で、押し出しが266ms、体のBVHの作り直しが117msだった。服を選ぶたびに約0.27秒、体型・身長を変えたときに約0.4秒で、服の読み込みと同じくらいの待ち時間として許容できる
- 極端に小さい服では、Eは服を体の大きさまで広げ、脇の下も崩れる（身幅を基準より8cm以上小さくしたとき）。「小さすぎます」で着せないようにすれば、崩れた形も、実寸より大きく見える服も見せずに済む

## 代替案

- Aだけ：計算が軽い（シェーダーだけ）が、服の外の体がくびれて見える
- A＋E：極端に小さい服でもきれいだったが、Aのくびれは残る
- Aの縮め方を必要な分だけにする：くびれは出にくいが、服の形を調べる計算が要り、手間はEと変わらない
- Eの押し出しの向きを服の法線にする、腕の内側の面を除く、押し出した部分をならす：どれも押しすぎや寸法のずれが出た

## 影響

- 体より小さい服（タイト）は、画面では入力より大きく見える。身幅を基準より6cm小さくした服で、見た目の身幅は4.6〜4.9cm大きかった
- 押し出しの計算中（スマホで0.3〜0.4秒）は画面が止まる。気になるなら、計算をWeb Workerに移す
- 伸び率（10%）は、服の素材によって本当は違う。今はTシャツ1着だけなので、固定にしている。のちに、シャツは3%にした（[ADR 0030](0030-layered-fit-status.md)）
- Blenderの検証スクリプトは、webと同じ押し出しを再現し、押し出した後の寸法のずれを出す。合否は押し出す前の寸法で決める
