# ズボンの切り抜きでは、ランドマークで囲んだ輪郭の外を背景として教える

日付：2026-10-17

## 背景

平置きのジーンズを撮ると、写真のほとんどが服の範囲（bbox）に入る。GrabCutが背景の色を学ぶ場所が足りず、脚の間や腰の外側の床が服として残った。切り抜きはクローゼットの表示と、テクスチャを作るときの服の領域の両方に使う。

## 決定

ズボンでは、DeepFashion2の14点を輪郭の順（1→2→3→14→…→9→…→4）につないだ多角形を手がかりにする。多角形を服の大きさの2%だけ広げた外側を「背景らしい」、6%広げた外側を「背景」としてGrabCutに渡す。9番（股）で脚の間へ折り返すので、脚の間も背景の候補になる。

`POST /v1/detections`のoptionsに任意の`points`を足し、cutout工程で前の工程のランドマークを受け取る。表は採寸で求めた点を渡す。裏面はgarment工程の代わりにlandmarks工程を使う。服の範囲と点を求めてから切り抜く。Tシャツの切り抜きは変えない。

## 理由

ランドマークは服の輪郭上に出るよう学習されているので、外側を背景として教えれば床の色を学べる。広げる幅を2段階にして、点が輪郭から少しずれても服を削らないようにした。

## 代替案

- bboxを小さくする：脚の間の床は残る。
- 脚の間の三角形だけを背景にする：腰の外側に残る床は取れない。
- 背景の色を別に指定してもらう：撮影の手間が増える。

## 影響

裏面の切り抜きは、ランドマークの推論の分だけ数秒長くかかる。点が大きく外れると服の一部が欠けることがある。脚の付け根の濃い影は、濃いデニムと色で見分けられず服に含まれることがある。
