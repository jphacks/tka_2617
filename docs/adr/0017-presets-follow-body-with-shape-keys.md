# 0017 髪・靴のプリセットは、骨格ではなく体と同じシェイプキーで体に合わせる

日付：2026-10-15

## 背景

アバターに髪型（4種）と靴（スニーカー）のプリセットを着けられるようにする。依頼では「素体・髪・靴を同じ原点・同じスケール・同じ骨格で書き出し、glbを重ねるだけで正しい位置に来る」ことが条件だった。一方、今の体（`avatar_male.glb`）は骨格を持たず、体型と身長をシェイプキー（体型キー3個＋身長キー2個）で変えている。Tシャツとジーンズも同じキーを持ち、ブラウザで体と同じ値を入れて重ねている。

## 決定

- 髪・靴は骨格を持たない。体と同じ原点・スケールで、体と同じ名前・同じ意味の体型キー3個＋身長キー2個を持つ
- キーの形はTシャツと同じ方法で作る。体型・身長を変えた体を作り、mhcloで着せ直す
- 色はブラウザで掛ける。髪と肌のテクスチャは明暗だけの灰色、靴は白の単色（その後、肌は色の差を残す形に、靴は灰色のテクスチャと靴下の材質に変えた）
- 靴で隠れる足は、体の頂点属性`_shoe`で示す（その後、靴が2種類になったので、靴ごとに`_shoe_<靴のid>`に分けた）。頂点グループはglbに出ないため
- 出力は`apps/web/public/presets/`、スクリプトは`assets/blender/`に置く

## 理由

- 骨格で合わせても、体型・身長はシェイプキーで変わるので、骨格だけでは頭の形や足の大きさの変化に追従しない。体と同じキーを持たせれば、ブラウザの処理は服と同じで済む
- 体型4種×身長150〜195cmで、靴・短い髪3種は体の面から2mmより内側に入る頂点が0〜4個（最大0.27cm）だった
- 灰色のテクスチャに色を掛ける形にすれば、髪の色6色・肌の色6色をテクスチャを増やさずに出せる

## 代替案

- 骨格を入れる：ポーズを付けられるようになるが、今の体型・身長キー、服の押し出し、寸法の表の作りと合わせ直す必要があり、作業がかなり増える。ポーズが必要になったら改めて考える
- 依頼どおり`assets/presets/`に置く：ブラウザから読めない。アプリで使うときは、別に`public`へコピーする必要がある

## 影響

- 体型・身長を変えたら、体・服・髪・靴のすべてに同じキーの値を入れる
- ロングヘア（`long01`）は、体に最大2.1cm（ぽっちゃり）入る頂点がある。描いた画像では目立たなかった。また背中に沿う髪は、服を着ると服の内側に入るおそれがあり、髪を服の外へ押し出す処理が要るかもしれない（未確認）
- 体を作り直したら（`build_tshirt.py`）、`render_presets.py`で確認し直す
