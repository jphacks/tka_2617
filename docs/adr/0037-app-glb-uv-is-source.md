# 0037 テクスチャのUVは、アプリのglbのUVを正とし、変換しない

日付：2026-10-17

## 背景

推論サービスは、型紙（`uv_template.json`）のUVに合わせてテクスチャを作る。アバターに貼るのはアプリのglb（`apps/web/public/models/*.glb`）で、型紙とUVが合わないと、#73で貼っても柄がずれる。ズボンと長そでの型紙は受け取ったglbから、Tシャツの型紙は`pitari.blend`から作っていて、アプリのglbと合うかは確かめていなかった（[ADR 0033](0033-serve-texture-through-api.md)）。

## 決定

- アプリのglbのUV（`TEXCOORD_0`）を正とする。テクスチャとglbの間で、UVを変換しない
- Tシャツの型紙は作り直さない。`tshirt_male.glb`のUVは、`pitari.blend`の`pitari`のUVと同じだった
- glbのUVを変えたら、型紙を作り直す。glbを書き出し直すPRには、UVを変えたかどうかを書く
- 書き忘れても気づけるよう、型紙にはアプリのglbのUVのハッシュを記録し、照合のスクリプトでglbと比べる（スクリプトはテクスチャ担当が作る。#67）
- three.jsで貼るときは、glTFのUVの向きに合わせて`texture.flipY = false`、色を正しく出すために`texture.colorSpace = SRGBColorSpace`にする（#73）

## 理由

推論サービスで作ったTシャツ・長そで・ズボンのテクスチャを、アプリのglbに次の2つの方法で当てて、3着ともずれないことを確かめた。

- glbのUVの三角形を、テクスチャの上に描いて重ねた。UVの島と、塗られた服の形が一致した
- Blenderで`avatar_male.glb`と服のglbを読み込み、テクスチャを貼って前と後ろから描画した。前の柄は胸に、後ろの柄は背中に乗り、えりぐり・すそ・そでの境目もずれなかった

runaも、Tシャツは`pitari.blend`とUVの組が一致、長そでは受け取ったglbとUV・頂点・三角形の並びが一致、ズボンは受け取ったglbと同じファイルであることを、数値で確かめた（#67のコメント）。

## 代替案

- 型紙のUVからアプリのglbのUVへ、テクスチャを変換する：UVが同じなので、変換しても結果は変わらない。処理と確かめる手間だけが増える
- glbのUVを型紙に合わせて作り直す：今は合っているので要らない。glbを作り直すたびに型紙と食い違うおそれも増える

## 影響

- 長そでは、三角形の約1.2%（面積で約0.9%）が、テクスチャの塗られていない黒い所に当たる。どれもそでのあたり。UVのずれではなく、型紙がその面に色を塗っていないため。テクスチャ側で余白を広げるか、塗る面を足して直す
- シャツ（`shirt_male.glb`）は服の種類になく、型紙もないので、今回は確かめていない。型紙を作るときに、同じ方法で確かめる
