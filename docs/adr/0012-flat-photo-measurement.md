# 真上撮影では画像を変形せず採寸する

日付：2026-10-10

## 背景

服とA4を同じ平面に置いて真上から撮影する。四隅の検出ミスや長辺・短辺の取り違えがあると、遠近補正によって表示画像が変形していた。

## 決定

画像全体の遠近補正をやめ、A4の長辺29.7cm・短辺21cmから、1つの縮尺を求める。画像と測定点の座標系は変えない。自動認識のあと、A4・服の範囲・ランドマークをドラッグして直せるようにする。

背景の除去には、既存のOpenCVのGrabCutを使う。検出した服の範囲と、A4を除くための領域を渡す。表示用の透過PNGを別roleで保存する。進捗は4工程の完了数で示し、時間経過で架空の割合を増やさない。

## 理由

撮影条件に合う単純な計算にし、四隅の誤差で服全体を引き伸ばさない。新しい依存・モデルダウンロードは不要。

## 代替案

斜め撮影の遠近補正は今回の撮影条件に不要。背景除去専用の学習済みモデルには、追加の資源が要る。最初の実装では、既存のOpenCVを使う。

## 影響

採寸バージョンをdf2-a4-flat-midpoint-v2へ更新する。斜め撮影・レンズゆがみ・服と紙の高さの差を補正する機能ではない。背景と服が似た色だと、切り抜きに失敗することがある。保存前のプレビューで確かめられる。従来のデータは計算し直さず、上書きもしない。
