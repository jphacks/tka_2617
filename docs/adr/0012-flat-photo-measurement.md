# 真上撮影では画像を変形せず採寸する

日付：2026-10-10

## 背景

服とA4を同じ平面に置いて真上から撮影する。四隅の誤検出や長短辺の取り違えを含む遠近補正により、表示画像が変形していた。

## 決定

画像全体への遠近補正を廃止し、A4の長辺29.7cm・短辺21cmから単一の縮尺を求める。画像と測定点の座標系を維持する。自動認識後にA4・服の範囲・ランドマークをドラッグ調整できるようにする。

背景除去は既存のOpenCVのGrabCutを使い、検出した服の範囲とA4の除外領域を与える。表示用の透過PNGを別roleで保存する。進捗は4工程の完了数で示し、時間経過で架空の割合を増やさない。

## 理由

撮影条件に合う単純な計算にし、四隅の誤差で服全体を引き伸ばさない。新しい依存・モデルダウンロードは不要。

## 代替案

斜め撮影の遠近補正は今回の撮影条件に不要。背景除去専用の学習済みモデルは追加の資源を必要とするため、初期実装には既存のOpenCVを使う。

## 影響

採寸バージョンをdf2-a4-flat-midpoint-v2へ更新する。斜め撮影・レンズゆがみ・服と紙の高さの差を補正する機能ではない。切り抜きは背景と服が似た色の場合に誤ることがあり、保存前のプレビューで確認できる。従来のデータは再計算・上書きしない。
