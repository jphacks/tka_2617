# アバターとプリセットの素材のライセンス

アバター（`/models/avatar_male.glb`、`/models/avatar_female.glb`）とプリセット（`/presets/`）は、MakeHumanの素材から`assets/blender/`のスクリプトで作った。使った素材はすべてCC0 1.0（[ライセンス本文](https://creativecommons.org/publicdomain/zero/1.0/legalcode)）。

各素材のファイルには「2020年9月にCC0として公開した」と書かれ、公開時点の著作権者は次のとおり。

- Data Collection AB（https://www.datacollection.se）
- Joel Palmius
- Jonas Hauquier
